# 中国劳动权益 AI Agent

面向中国大陆劳动者的开源劳动权益 AI 助手。

帮助劳动者用自然语言整理劳动事实、证据、补偿估算和仲裁材料。

项目专注中国劳动法律场景，不提供海外劳动法通用服务。

支持 AI 工作流：

- OpenAI Codex
- Claude Code
- OpenCode
- OpenClaw
- MCP 工具链

> 目标：让每个劳动者都拥有一个自己的劳动权益分析助手。

---

## 适用场景

- 突然被辞退，不知道是否存在解除风险
- 公司要求立即签署解除协议
- 欠薪、加班、社保问题需要整理
- 不清楚应该保存哪些维权证据
- 需要准备劳动仲裁材料

---

## 能做什么

### 事实整理

帮助拆解：

- 发生了什么
- 哪些事实已确认
- 哪些信息需要补充

### 证据整理

帮助建立：

- 合同
- 工资记录
- 考勤
- 沟通记录
- 工作成果

### 权益分析

辅助理解：

- 解除风险
- 补偿计算逻辑
- 劳动争议重点

### 材料准备

辅助生成：

- 沟通方案
- 事实说明
- 仲裁材料草稿

## 安全边界

本项目：

- 不是律师
- 不是政府服务
- 不提供个案代理
- 不保证仲裁或诉讼结果

请结合最新法规、当地规则和专业意见判断。

不要上传未脱敏身份证、银行卡、合同等敏感材料。

---

## 确定性工资记录导入

补偿计算器可以读取最多 12 个月、仅含 `month,gross_wage` 两列的 UTF-8 CSV，在不保存源文件的前提下输出规范化记录、源文件 SHA-256、缺失月份、工资合计、平均工资及 N/N+1/2N 估算路径。缺失期间、工资口径和法律适用条件仍需核验。
