# Worker Rights CN 项目定位

## 核心定位

Worker Rights CN 是一个面向中国大陆劳动者的开源劳动权益 AI Agent。

项目专注于中国劳动关系场景，不追求通用海外劳动法律服务。

## 解决的问题

帮助劳动者：

- 梳理劳动事实
- 整理维权证据
- 理解劳动合同风险
- 辅助估算经济补偿
- 准备沟通和仲裁材料

## 为什么不做海外版

不同国家劳动法律制度、司法体系、劳动关系规则差异巨大。

本项目选择深耕中国劳动权益场景，通过本地法规、案例和实践流程提升准确性。

未来扩展方向不是复制到不同国家，而是深化中国劳动场景能力：

- 劳动法规知识库
- 劳动争议案例库
- 地区规则差异
- Agent 工作流
- MCP 工具接口

## AI 宿主定位

AI 工具只是使用入口：

- Codex
- Claude Code
- OpenCode
- OpenClaw
- MCP 客户端

核心资产仍然是中国劳动权益知识、流程和分析能力。
